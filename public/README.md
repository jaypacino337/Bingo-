# public/

Drop these two files in before you launch.

### `host.png` — required for the caller

The avatar of whoever is calling the game. It shows up twice:

1. As the circular portrait on the left of the hall.
2. As the face on the 3D caller stood next to the cage, turning the crank.

**Format:** square PNG, 512×512 or larger, ideally with the face centred —
it gets cropped to a circle in both places.

Until you add it, both fall back to a plain green placeholder. Nothing breaks,
it just looks generic.

### `og.png` — optional

1200×630 preview image for Twitter/Telegram link unfurls.
